# Deploy V6.4

Deploy by copying this folder over the GitHub repository working tree, excluding `.git`, then commit and push to `main`. Vercel should deploy automatically.

No Vercel environment-variable changes are required. Existing GA4, Resend and Cloudflare Turnstile variables remain unchanged.
